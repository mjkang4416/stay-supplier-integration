용어

이 문서에서 쓴 말이에요.

저하 모드degraded
Redis 에 값이 없거나 Redis 가 죽었을 때 검색이 공급사를 직접 부르는 상태예요. 응답의 fresh 가 true 로 나와요.
델타delta
크론잡이 공급사 목록과 DB 의 active 집합을 비교해 추가·변경·사라짐만 반영하는 방식이에요. 행은 지우지 않고 active=false 로만 둬요.
상태 키stay:v1:status:{supplier}
갱신 잡이 공급사별 마지막 성공·실패 시각과 사유를 적는 Redis Hash 예요. 검색이 읽어 failures 에 드러내요.
묶음chunk
재고·요금 API 가 한 번에 받는 숙소 코드 50개 단위예요. 묶음마다 따로 호출하고 실패도 묶음 단위로 가둬요.
미상unknown occupancy
공급사가 maxOccupancy 를 주지 않은 객실 타입이에요. 기본값을 넣지 않고 null 로 저장하고, 응답에서는 재고·요금 응답 값 → 매핑 값 순으로 채워요.
표준 형태stay/ package
어댑터가 공급사 응답을 바꿔 주는 공통 레코드예요(SupplierHotel, SupplierRoomOffer, SupplierDailyOffer). 어댑터 밖에서는 이것만 봐요.
